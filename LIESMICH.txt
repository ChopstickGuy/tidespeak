ASM-Speak v2 - verschluesselter Text- und Sprachchat in x64-Assembler
=====================================================================

STARTEN
  1. server.exe starten (Windows-Firewall: Zugriff zulassen).
     Beim ersten Start entsteht server_schluessel.bin - das ist die
     Identitaet des Servers. Gut aufheben, nicht weitergeben!
  2. client.exe starten, Server (IP oder Name, z.B. 127.0.0.1) und Namen
     eintragen, "Verbinden". Kein Login noetig.
  3. Der Client zeigt den Server-Fingerabdruck an. Er muss mit dem im
     Server-Fenster uebereinstimmen - dann redest du wirklich mit deinem Server.

  Die Dateien libsodium-26.dll und libopus-0.dll muessen neben den EXEs liegen.

BEDIENUNG
  Enter im Eingabefeld     Nachricht senden
  F2 gedrueckt halten      Sprechen (Push-to-Talk, auch wenn das Fenster im
                           Hintergrund ist)
  "Dauersenden"            offenes Mikrofon statt Push-to-Talk
  "Mikrofon stumm"         nichts senden
  Liste rechts             ● = spricht gerade
  Server und Name werden in asmspeak.ini gespeichert.

SICHERHEIT (libsodium)
  - Server hat einen festen Ed25519-Schluessel (Fingerabdruck)
  - pro Verbindung neue X25519-Schluessel -> Forward Secrecy
  - Text: XChaCha20-Poly1305 (secretstream), Reihenfolge/Manipulation geprueft
  - Sprache: ChaCha20-Poly1305, Zaehler gegen wiederholte Pakete (Replay)
  - Der Server entschluesselt und verschluesselt Sprache pro Empfaenger neu
    (wie TeamSpeak/Discord: Transportverschluesselung, kein Ende-zu-Ende)

AUDIO
  Opus, 48 kHz mono, 20-ms-Pakete, 32 kbit/s (statt 768 kbit/s roh)
  Jitter-Puffer 40 ms, mehrere Sprecher werden gemischt (SSE2)

NETZWERK
  Port 9987 TCP + UDP (fuers Internet beide im Router weiterleiten)

DATEIEN
  server.asm     Server (Konsole): Thread pro Client + UDP-Thread
  client.asm     Client (Fenster): GUI, Netzwerk, Opus, Mischer
  proto.inc      Protokoll + Krypto (gemeinsam)
  common.inc     Hilfsroutinen
  client.rc / app.manifest   modernes Aussehen + DPI
  lib\           Import-Bibliotheken fuer libsodium/libopus
  build.bat / build.sh       Bauen
